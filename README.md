# Dashboard-de-Performance-de-Vendas---Gatito-Petshop
Este projeto consiste em um dashboard interativo desenvolvido no Power BI para análise de vendas e faturamento de um Petshop. O objetivo é fornecer uma visão clara sobre o desempenho financeiro, comportamento do consumidor por gênero e distribuição geográfica das vendas em bairros de São Paulo.

🚀 Tecnologias Utilizadas
Power BI: Construção das visualizações e dashboards interativos.

DAX (Data Analysis Expressions): Criação de medidas para cálculo de faturamento total, ticket médio e contagem de vendas.

Power Query: Processamento e limpeza dos dados (ETL).

Modelagem Star Schema: Estruturação de dados em tabelas fato e dimensão para otimização de performance.

📈 Principais Indicadores (KPIs)
O dashboard apresenta três métricas centrais para a saúde do negócio:

Faturamento Total: R$ 2,03 Milhões.

Média de Pets: 2,61 por cliente.

Quantidade de Vendas: 57 Mil transações.

🔍 Funcionalidades e Análises
Análise Temporal: Gráfico de área mostrando a evolução do faturamento entre 2021 e 2022, permitindo identificar picos de venda (ex: jan/2022 com R$ 121 mil).

Distribuição Geográfica: Ranking de faturamento por bairro, destacando Itaquera (R$ 0,66 Mi) e Guaianases (R$ 0,63 Mi) como os principais mercados.

Demografia de Consumo: Gráfico de rosca evidenciando que o público feminino representa a maioria das compras (54,78%).

Filtros Dinâmicos: Segmentação por intervalo de datas e marca do produto, permitindo análises granulares.

Busca de Produtos: Filtro de texto e visualização de catálogo de produtos para facilitar a identificação de itens específicos.
